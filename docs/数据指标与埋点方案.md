## 一、指标体系总览

### 1.1 指标分层

```
校园二手闲置交易平台 指标体系
├── 北极星指标：月活跃买家数（MAU-Buyer）
├── 一级指标（核心指标）
│   ├── 用户规模：DAU/MAU、新增用户数、用户留存率
│   ├── 供给侧：在售商品数、新增发布数、卖家活跃度
│   ├── 核心功能：书单匹配使用率、搜索成功率、私信沟通率
│   └── 交易转化：商品详情浏览量、联系卖家率、线下成交率（估算）
└── 二级指标（辅助指标）
    ├── 页面级：各页面PV/UV、停留时长、跳出率
    ├── 功能级：各功能点击率、完成率、异常率
    ├── 用户行为：浏览深度、搜索关键词分布、收藏行为
    └── 内容质量：商品图片覆盖率、描述完整度、认证用户占比
```

### 1.2 北极星指标定义

**月活跃买家数（MAU-Buyer）：** 自然月内至少浏览过1次商品详情页的独立用户数。

**选择原因：**
- 买家是平台的需求侧核心，买家活跃度决定平台的交易活力
- 「浏览商品详情」是购买决策的关键动作，比「打开App」更能反映真实交易意愿
- 与供给侧（卖家）形成飞轮效应：更多买家 → 更多成交 → 更多卖家入驻 → 更多商品 → 更多买家

### 4.2 埋点实现说明

**V1.0阶段：** 埋点事件已在代码中预留埋点位置（关键操作处添加注释 `// TODO: 埋点 EV_XXX`），但实际数据上报功能暂不实现（MVP阶段无后端接收）。所有埋点事件定义与参数已在本文档中完整规划，V2.0对接后端时可直接按此方案实现。

**V2.0实现方案：**
1. 前端封装统一埋点函数 `track(eventId, params)`，内部调用后端埋点API
2. 后端接收埋点数据，写入日志文件/消息队列
3. 离线计算（每日凌晨）统计各指标，生成数据看板
4. 实时指标（DAU/在线人数）通过流式计算实现

### 4.3 关键漏斗模型

#### 4.3.1 买家交易漏斗

```
打开App → 浏览首页/分类 → 搜索/浏览商品 → 点击商品详情 → 联系卖家 → 私信沟通 → 线下成交
  100%       80%            60%            40%           15%         10%        5%（估算）
```

**核心关注节点：**
- 搜索→详情点击率：衡量搜索结果质量
- 详情→联系卖家率：衡量商品详情页转化能力
- 联系→成交率：衡量线下交易转化（V1.0通过私信关键词估算）

#### 4.3.2 卖家发布漏斗

```
打开App → 点击发布 → 填写表单 → 提交发布 → 发布成功 → 获得咨询 → 线下成交
  100%       90%        70%        60%       60%        30%        15%（估算）
```

**核心关注节点：**
- 发布页→提交率：衡量发布表单体验
- 提交→成功率：衡量表单校验合理性（失败率过高说明校验过于严格或提示不清晰）
- 发布→咨询率：衡量商品曝光与吸引力

#### 4.3.3 书单匹配核心漏斗

```
进入二手书专区 → 切换书单匹配Tab → 输入书单 → 点击开始匹配 → 匹配成功 → 展开卖家 → 联系卖家
    100%              40%              35%         30%          24%        15%         8%
```

**核心关注节点：**
- 专区→匹配Tab切换率：衡量核心功能曝光与吸引力
- 输入→匹配率：衡量用户输入完成度
- 匹配→展开率：衡量匹配结果吸引力
- 展开→联系率：衡量匹配结果转化为交易沟通的能力
